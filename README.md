# Food Reels Full Stack App

A full-stack food reels application where users can upload and watch short food videos. The app includes user authentication, video upload, and a clean feed-style interface similar to modern short-video platforms.

## Features

- User signup and login
- Authentication-based access
- Upload food reel videos
- Watch uploaded food reels in a feed
- Responsive user interface
- Backend API for user and video management
- Secure handling of user data

## Tech Stack

### Frontend
- React
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
